# Risorse e Link Utili per la Gestione delle Impostazioni in Laravel

In questo file trovi una raccolta di link a pacchetti, plugin, guide e strumenti utili per la gestione delle impostazioni, log viewer e monitoring in Laravel/Filament. Ogni link è accompagnato da una breve descrizione e, dove disponibile, il comando composer per l'installazione rapida.

## Gestione Impostazioni e Settings
- [Guida: Setting Page con Filament](https://blog.moonguard.dev/setting-page-with-filament)
  > Tutorial su come creare una pagina di impostazioni personalizzata in Filament.
- [reworck/filament-settings (Gestione impostazioni con Filament)](https://github.com/reworck/filament-settings)
  > Plugin per la gestione centralizzata delle impostazioni tramite Filament.
- [spatie/valuestore (Key-Value Store semplice)](https://github.com/spatie/valuestore)
  > Pacchetto per gestire impostazioni key-value in modo semplice e veloce.
- [Esempio: Custom Page in Filament con Repeater](https://laraveldaily.com/post/filament-custom-page-example-with-repeater)
  > Esempio pratico di pagina custom con campo repeater in Filament.
- [filamentphp/spatie-laravel-settings-plugin](https://github.com/filamentphp/spatie-laravel-settings-plugin)
  > Plugin ufficiale per integrare spatie/laravel-settings in Filament.
- [Restrizioni di accesso su Filament Settings Plugin (Q&A)](https://stackoverflow.com/questions/76164468/how-to-restrict-access-to-filament-spatie-laravel-settings-pluginpage-with-polic)
  > Discussione su StackOverflow riguardo la protezione delle pagine di settings.

## Log Viewer
- [Log Viewer: Guida e Plugin](https://codebrisk.com/blog/a-fast-and-beautiful-laravel-log-viewer-with-search-option)
  > Guida e presentazione del plugin Log Viewer per Laravel.
  ```bash
  composer require opcodesio/log-viewer
  ```

## Monitoring e Query
- [Monitoring Query: Guida](https://codebrisk.com/blog/configurable-app-query-capturing-monitoring-in-laravel)
  > Guida su come monitorare le query dell'applicazione Laravel.
  ```bash
  composer require YorCreative/Laravel-Query-Watcher
  ```
