# Consolidamento documentazione e standardizzazione

## Obiettivo

Consolidare i documenti ridondanti, uniformare naming e mantenere link coerenti e bidirezionali.

## Passi operativi

1. Inventariare file duplicati o obsoleti.
2. Normalizzare naming con kebab-case.
3. Consolidare documenti sovrapposti in un unico riferimento.
4. Aggiornare link interni con percorsi relativi.
5. Verificare coerenza tra summary, report e roadmap.

## Criticita

- Rischio di perdere contenuti utili durante la fusione.
- Link interni non aggiornati dopo rinomini.

## Punti di forza

- Presenza di piani di consolidamento gia definiti.
- Struttura docs ampia con sezioni tematiche.

## Punti di debolezza

- File storici con naming non uniforme.
- Sovrapposizione di report simili.

## Colli di bottiglia

- Molteplici file con lo stesso tema ma versioni diverse.
- Mancanza di un indice unico stabile.

## Come risolverli

- Usare check-list di consolidamento.
- Documentare ogni merge in un file di summary.
- Introdurre un indice consolidato.

## Religione

- La documentazione e parte del prodotto, non un accessorio.

## Filosofia

- Un solo punto di verita per ogni tema.

## Politica

- Nessuna rimozione senza migrazione o archiviazione.

## Output attesi

- Documentazione coerente e navigabile.
- Riduzione della ridondanza.
