# FixCity Platform - Project Context

## Project Overview
FixCity is a citizen reporting platform for urban issue management. Citizens report problems (potholes, broken lights, etc.), and administrators manage them through a complete workflow.

## System Architecture
- **Modular Monolith**: Nwidart/Laravel-Modules + Laraxot extensions
- **Backend**: Laravel 12.24.0 + PHP 8.3.20 + SQLite
- **Backoffice**: Filament 3.x + Laraxot (admin panels for staff)
- **Frontoffice**: Folio + Volt + Livewire 3.x (citizen-facing interface)
- **Theme**: Sixteen (active theme)

## Key Models & Relations

### Ticket (Core Entity)
- Extends: XotBaseModel (Laraxot pattern)
- belongsTo: owner, responsible (User)
- hasMany: activities, hours, comments, relations
- Supports: geolocation, media attachments, status tracking
- Uses: Enums for status/priority/type

## Routing Patterns
- **NO Traditional Routes**: web.php and api.php are EMPTY
- **Folio Frontend** (citizen-facing): File-based routing
  - `/it/tickets/create` → Themes/Sixteen/resources/views/pages/tickets/create.blade.php
  - `/it/tickets/{slug}` → Modules/Fixcity/resources/views/pages/tickets/[slug].blade.php
- **Filament Admin Panels** (staff-facing): Auto-generated resources
  - `/fixcity/admin/tickets` → Auto-generated by TicketResource
  - `/user/admin/users` → Auto-generated by UserResource

## Development Workflow
1. **Frontend changes**: Work in `Themes/Sixteen/`
2. **CSS/JS changes**: Always run `npm run build && npm run copy`
3. **New pages**: Use `php artisan folio:page`
4. **Admin features**: Create Filament Resources
5. **Interactivity**: Use Livewire Volt components
6. **Models**: Extend XotBaseModel (never direct Eloquent Model)
7. **Testing**: Use Pest for all tests
8. **Documentation**: Update docs/ with every change

## Laraxot Patterns
- **Base Classes**: Always extend Xot* base classes
- **Service Providers**: Extend XotBaseServiceProvider
- **Models**: Extend XotBaseModel with Updater Trait
- **Translation Format**: 5 levels - `namespace::context.collection.element.type`
  - Example: `fixcity::segnalazione.fields.title.label`
- **Widget Naming**: Use `Ticket` NOT `Segnalazione` in class names

## Critical Rules
1. **NO hardcoded language strings**: ALL text must use translation helpers
2. **HTML Structural Parity**: Replicate exact HTML structure from reference designs
3. **NO Bootstrap CSS/JS files**: Use TailwindCSS @apply in style-apply.css
4. **NO data-bs-* attributes**: Use Alpine.js for interactivity (x-data, @click, x-show)
5. **Forward-Only Git**: NEVER reset, revert, or checkout old commits
6. **Widget Architecture**: NO Filament schemas wizard in frontoffice (no JS assets available)

## Business Logic

- Administrative workflow with assignments and status tracking
- Multi-channel notifications and updates
- Complete audit trail and reporting
