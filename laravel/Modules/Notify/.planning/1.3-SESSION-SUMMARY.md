## Key Lessons (Memory Bank)
1. Vite css-only build destroys manifest → Always merge JS entry back
2. Filament CSS bundled into theme → Override with `html body` + `!important`
3. Playwright selectors need precision → `.btn.btn-primary` matches header links too
4. Computed styles > HTML diff for visual parity measurement
5. 1-unit color diffs (rgb 25 vs 26) are sub-visual
