## 🎯 KEY BOOTSTRAP ITALIA CLASSES

### Layout
- `.container` - Main container
- `.row` - Row grid
- `.col-12`, `.col-md-4`, `.col-lg-3` - Columns
- `.g-4` - Gap spacing

### Header
- `.it-header-wrapper` - Main header wrapper
- `.it-header-slim-wrapper` - Top bar
- `.it-header-center-wrapper` - Center section
- `.it-header-navbar-wrapper` - Navigation
- `.it-brand-wrapper` - Logo/brand
- `.it-socials` - Social media links

### Components
- `.card` - Base card
- `.card-bg` - Card with background
- `.card-teaser` - Teaser card
- `.card-body` - Card body
- `.card-title` - Card title
- `.btn` - Button
- `.btn-primary` - Primary button
- `.btn-icon` - Icon button

### Navigation
- `.navbar` - Navigation bar
- `.navbar-nav` - Nav list
- `.navbar-expand-lg` - Expand on large screens
- `.nav-link` - Nav item link
- `.dropdown` - Dropdown menu
- `.dropdown-menu` - Dropdown content

### Utilities
- `.visually-hidden` - Screen reader only
- `.visually-hidden-focusable` - Hidden until focused
- `.d-none`, `.d-lg-block` - Display utilities
- `.text-center` - Text alignment
- `.shadow-sm` - Small shadow
- `.rounded` - Rounded corners
