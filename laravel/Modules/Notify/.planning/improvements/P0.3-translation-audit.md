## Critical Issues

### 1. Structure Inconsistency (P0)

**Problem:** Modules use different directory structures for translations.

**Laraxot Standard:** `Modules/*/resources/lang/it/`  
**Legacy Pattern:** `Modules/*/lang/it/`

**Modules Requiring Migration:**
```
AI/          - lang/it/ → resources/lang/it/
Comment/     - lang/it/ → resources/lang/it/
Fixcity/     - lang/it/ → resources/lang/it/  [CRITICAL - Core module]
Geo/         - lang/it/ → resources/lang/it/
Media/       - lang/it/ → resources/lang/it/
Rating/      - lang/it/ → resources/lang/it/
Seo/         - NO TRANSLATIONS FOUND
Tenant/      - lang/it/ → resources/lang/it/
UI/          - lang/it/ → resources/lang/it/
```

### 2. Duplicate Structures (P1)

**Problem:** Some modules have BOTH `lang/it/` AND `resources/lang/it/`, creating confusion and potential inconsistency.

**Affected Modules:**
- Activity (13 legacy + 2 standard)
- Blog (26 legacy + 15 standard)
- Cms (45 legacy + 26 standard)
- Gdpr (9 legacy + 2 standard)
- Job (13 legacy + 13 standard - possible exact duplicate)
- Lang (22 legacy + 4 standard)
- Notify (49 legacy + 10 standard)
- User (98 legacy + 16 standard)
- Xot (61 legacy + 7 standard)

**Action Required:** Audit for differences, consolidate to standard structure.

### 3. Placeholder Strings (P1)

**Found in:** `User/lang/it/login.php`

```php

    'label' => 'Missing Navigation Label',        // ❌ English placeholder
```

**Impact:** Users see untranslated UI elements.

## File Structure Standard

**Target Structure:**
```
Modules/ModuleName/
├── resources/
│   └── lang/
│       ├── it/           # Italian translations
│       │   ├── auth.php
│       │   ├── navigation.php
│       │   ├── validation.php
│       │   └── module-specific.php
│       └── en/           # English fallback (optional)
└── lang/                 # TO BE REMOVED after migration
```

**File Naming Convention:**
- `auth.php` - Authentication messages
- `navigation.php` - Menu and navigation labels
- `validation.php` - Validation error messages
- `pagination.php` - Pagination controls
- `passwords.php` - Password reset messages
- `{module}.php` - Module-specific translations (e.g., `ticket.php`, `user.php`)
