## Anti-Patterns (NON FARE)

| ❌ SBAGLIATO | ✅ CORRETTO |
|---|---|
| Hardcoded italiano in PHP | `__('fixcity::segnalazione.*')` |
| TextEntry in Form Schema | `Text` (Schemas component) |
| Placeholder (deprecated) | `Text::make()->state()` |
| Sezione senza heading | `Section::make()->heading()` |
| CSS inline nel Blade | File CSS dedicato |
