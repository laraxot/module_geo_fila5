# Modulo Notify: valore operativo e release tracciabile

Notification management module for the Laraxot ecosystem: email, SMS, WhatsApp, Telegram, and FCM push.

## Perche guardarlo adesso

- Documentazione e changelog nello stesso flusso del codice.
- Semantic versioning e release automatizzate dove configurate.
