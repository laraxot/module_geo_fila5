# Laraxot Git Conflicts

## Scopo
Risolvere conflitti Git in modo manuale, documentato e conforme a PHPStan.

## Checklist
- [ ] Identifica file in conflitto
- [ ] Leggi file completi e contesto
- [ ] Aggiorna docs del modulo/tema
- [ ] Risolvi conflitto manualmente (no auto-merge)
- [ ] Verifica PHPStan level 10 sul modulo
- [ ] Esegui test mirati

## Regole chiave
- Mai usare risoluzioni automatiche
- Mantenere coerenza architetturale Laraxot
- Aggiornare la documentazione correlata
