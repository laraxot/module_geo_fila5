  <action>
    For each critical model (Performance evaluation, Indemnity, User, Role):
    1. Add `use Spatie\Activitylog\Traits\LogsActivity;`
    2. Add trait to model class: `use LogsActivity;`
    3. Implement `getActivitylogOptions()` method returning `Activity::logAll()`
    4. Ensure all relevant fields are logged (no exclude for sensitive fields like password)
    
    Example pattern:
    ```php
    use Spatie\Activitylog\Traits\LogsActivity;
    
    class PerformanceEvaluation extends XotBaseModel
    {
        use LogsActivity;
        
        public function getActivitylogOptions(): ActivitylogOptions
        {
            return Activity::logAll()
                ->submitLogs($shouldSubmitLogs())
                -> chainMultipleLogTypes()
                ->keepLogExcept('updated_at');
        }
    }
    ```
  </action>
  <verify>Each model has getActivitylogOptions() returning Activity::logAll()</verify>
  <done>All critical models log before/after values</done>
</task>
