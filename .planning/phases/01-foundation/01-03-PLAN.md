<context>
## Data Retention Requirements

Italian PA regulations (D.Lgs. 150/2009):
- Performance evaluations: Retain for minimum 5 years
- Financial records: Retain for minimum 10 years
- Attendance records: Retain for minimum 5 years
- GDPR: Anonymize when no longer needed, delete after retention period

Research flag: Test retention policies with large datasets (1000+ employees)
</context>

    2. For each record type:
       - Archive: Move to archive table or set is_archived flag
       - Delete: Anonymize PII, then hard delete
    3. Log all retention actions to retention_logs
    4. Return report of actions taken
    
    Pattern:
    ```php

    {
        public function execute(string $modelType): RetentionReport
        {
            $records = $modelType::eligibleForRetention()
                ->chunk(100, function ($chunk) {
                    foreach ($chunk as $record) {
                        $this->applyPolicy($record);
                    }
                });
            
            return new RetentionReport([...]);
        }
    }
    ```
