## 1. FUNDAMENTAL PRINCIPLES

### Single Source of Truth
The Filament field exposes a single composite state (e.g. `location`) with shape:
```php
[
    'latitude'       => null,
    'longitude'      => null,
    'address'        => '',
    'address_details'=> null,
    'street'         => '',
    'street_number'  => '',
    'city'           => '',
    'postcode'       => '',
    'state'          => '',
    'province'       => '',
    'country'        => '',
    'country_code'   => '',
    'suburb'         => '',
]
```
DB columns remain `latitude` and `longitude`, populated via explicit mapping in `extractCoordinates()`.

### XotBaseField
Every custom Filament field in the Geo module MUST extend `Modules\Xot\Filament\Forms\Components\XotBaseField`.

### Sibling Architecture
Components are siblings, NOT a hierarchy. `LatitudeLongitudeInput` does NOT extend `CoordinatePicker`.
All use `HasCoordinatePicker` trait for shared configuration logic.

### Leaflet Isolation
Leaflet attaches to its container via local classes (`.coordinate-picker-map`), NEVER via global IDs.
Do NOT use `id="map"` or `document.getElementById()`.

### Lit Component — Light DOM preferred
Use Light DOM (not Shadow DOM) for maximum compatibility with Leaflet CSS, panes and controls.
Emit semantic events: `coords-changed`, `fullscreen-changed`.

### Alpine Adapter — Minimal Bridge
Alpine is the thin sync layer between Livewire (`$wire.$set` / `$wire.$watch`) and Lit properties/events.
Keep it as thin as possible — no business logic in Alpine.

### Livewire — Server Authority
Livewire handles: persistence, server calls (reverse geocoding / address search via Nominatim), server-side validation.

## 4. MAP CONTROLS (IMPLEMENTATION)

### 4 Required Tile Layers
```js
// coordinate-picker-lit.js

_initLayers() {
    // Layer 1: OSM Standard
    this._layers.street = L.tileLayer(
        'https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png',
        { attribution: '&copy; <a href="https://www.openstreetmap.org/copyright">OpenStreetMap</a>', maxZoom: 19 }
    ).addTo(this._map);

    // Layer 2: OSM Humanitarian (HOT)
    this._layers.humanitarian = L.tileLayer(
        'https://{s}.tile.openstreetmap.fr/hot/{z}/{x}/{y}.png',
        { attribution: '&copy; OpenStreetMap, Tiles courtesy of HOT', maxZoom: 19 }
    );

    // Layer 3: Esri World Imagery (Satellite)
    this._layers.satellite = L.tileLayer(
        'https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}',
        { attribution: '&copy; Esri &mdash; Source: Esri, USGS, AeroGRID, IGN', maxZoom: 19 }
    );

    // Layer 4: Esri World Topographic
    this._layers.topo = L.tileLayer(
        'https://server.arcgisonline.com/ArcGIS/rest/services/World_Topo_Map/MapServer/tile/{z}/{y}/{x}',
        { attribution: '&copy; Esri', maxZoom: 19 }
    );

    L.control.layers(
        {
            [this.labels?.layers?.street      || 'Stradale (OSM)']      : this._layers.street,
            [this.labels?.layers?.humanitarian || 'Umanitaria (OSM)']   : this._layers.humanitarian,
            [this.labels?.layers?.satellite    || 'Satellitare (Esri)'] : this._layers.satellite,
            [this.labels?.layers?.topographic  || 'Topografica (Esri)'] : this._layers.topo,
        },
        null,
        { position: 'topright' }
    ).addTo(this._map);
}
```

### Zoom Controls

```js
_zoomOut() { this._map?.zoomOut(); }
```
Pair with Leaflet's `zoomControl: false` on map init to avoid duplicate controls.

### Fullscreen Toggle
```js
_toggleFullscreen() {
    this.isExpanded = !this.isExpanded;
    this.isFullscreen = this.isExpanded;

    if (this.isExpanded) {
        document.body.style.overflow = 'hidden';
        this.style.position = 'relative';
        this.style.zIndex = '2147483647';
    } else {
        document.body.style.overflow = '';
        this.style.removeProperty('position');
        this.style.removeProperty('z-index');
    }

    this.dispatchEvent(new CustomEvent('fullscreen-changed', {
        detail: { isFullscreen: this.isFullscreen },
        bubbles: true,
        composed: true,
    }));

    setTimeout(() => {
        this._map?.invalidateSize();
        if (this.isExpanded) this._map?.setZoom(Math.max(this._map.getZoom(), 14));
    }, 300);
}
```

### Current Location (Geolocation) — EXPLICIT ONLY
```js
_requestGeolocation() {
    if (!navigator.geolocation) return;
    this.isLocating = true;
    navigator.geolocation.getCurrentPosition(
        (pos) => {
            this._handleMapInteraction(pos.coords.latitude, pos.coords.longitude, 'geolocation');
            this._map?.setView([pos.coords.latitude, pos.coords.longitude], 16);
            this.isLocating = false;
        },
        () => { this.isLocating = false; },
        { enableHighAccuracy: true, timeout: 5000, maximumAge: 300000 }
    );
}
```
**IMPORTANT**: Never call `_requestGeolocation()` automatically on mount. It is an EXPLICIT user action.

## 5. ADDRESS SEARCH (GEOCODING)

### PHP — Server-Side via Livewire
Add to `HasCoordinatePicker` trait:
```php
#[ExposedLivewireMethod]
#[Renderless]
public function searchAddress(string $query): array
{
    if (strlen(trim($query)) < 3) {
        return [];
    }

    try {
        $response = Http::withHeaders([
            'User-Agent' => config('app.name', 'Laraxot') . '/1.0',
        ])
        ->timeout(10)
        ->get('https://nominatim.openstreetmap.org/search', [
            'q'              => $query,
            'format'         => 'json',
            'addressdetails' => 1,
            'limit'          => 5,
            'countrycodes'   => 'it',
        ]);

        if (! $response->successful()) {
            return [];
        }

        $data = $response->json();
        return is_array($data) ? $data : [];
    } catch (\Throwable) {
        return [];
    }
}
```

### Alpine — Search Integration
```blade
{{-- In coordinate-picker.blade.php, inside x-data --}}
searchQuery: '',
searchResults: [],
isSearching: false,
showResults: false,

async searchAddress() {
    if (this.searchQuery.length < 3) {
        this.searchResults = [];
        this.showResults = false;
        return;
    }
    this.isSearching = true;
    try {
        const results = await this.$wire.callSchemaComponentMethod(
            '{{ $id }}',
            'searchAddress',
            { query: this.searchQuery }
        );
        this.searchResults = results || [];
        this.showResults = this.searchResults.length > 0;
    } catch (e) {
        this.searchResults = [];
        this.showResults = false;
    }
    this.isSearching = false;
},

selectSearchResult(result) {
    const lat = parseFloat(result.lat);
    const lon = parseFloat(result.lon);
    this._lat = lat;
    this._lng = lon;
    this.searchQuery = result.display_name;
    this.searchResults = [];
    this.showResults = false;
    void this.reverseGeocode(lat, lon);
},
```

### Alpine — handleCoordsChanged (Full State)
```js
handleCoordsChanged(event) {
    const { latitude, longitude } = event.detail;
    this._suppressUpdate = true;
    this._lat = latitude;
    this._lng = longitude;

    const newState = {
        latitude,
        longitude,
        address: this.address,
        address_details: this.structured,
        street:        this.structured?.road     || this.structured?.street || '',
        street_number: this.structured?.house_number || this.structured?.street_number || '',
        city:          this.structured?.city     || '',
        postcode:      this.structured?.postcode || '',
        state:         this.structured?.state    || '',
        province:      this.structured?.county   || '',
        country:       this.structured?.country  || '',
        country_code:  this.structured?.country_code || '',
        suburb:        this.structured?.city_district || this.structured?.suburb || '',
    };

    this.$wire.$set('{{ $statePath }}', newState);
    setTimeout(() => { this._suppressUpdate = false; }, 350);
    void this.reverseGeocode(latitude, longitude);
},
```

### Alpine — reverseGeocode callback (Full State Hydration)
```js
async reverseGeocode(lat, lng) {
    if (!lat || !lng) return;
    try {
        const result = await this.$wire.callSchemaComponentMethod(
            '{{ $id }}',
            'reverseGeocode',
            { latitude: lat, longitude: lng }
        );
        if (result) {
            this.address   = result.display_name || '';
            this.structured = result.structured  || null;
            this.$wire.$set('{{ $statePath }}', {
                latitude:      lat,
                longitude:     lng,
                address:       this.address,
                address_details: this.structured,
                street:        result.street        || '',
                street_number: result.street_number || '',
                city:          result.city          || '',
                postcode:      result.postcode      || '',
                state:         result.state         || '',
                province:      result.province      || '',
                country:       result.country       || '',
                country_code:  result.country_code  || '',
                suburb:        result.suburb        || '',
            });
        }
    } catch (_e) { /* swallow: geocoding is best-effort */ }
}
```

## 7. LIVEWIRE PERFORMANCE

### What Triggers a Livewire Update
| Event           | Should update Livewire? |
|-----------------|------------------------|
| `mousemove`     | Never               |
| `drag` (during) | Never               |
| `dragend`       | Yes                 |
| `click on map`  | Yes                 |
| `geolocation`   | Yes                 |
| `address select`| Yes (via reverseGeocode) |

### Debounce Settings
```js
// Search input
@input.debounce.500ms="searchAddress()"

// Suppress Livewire re-entrant updates after $wire.$set
this._suppressUpdate = true;
// ... do $wire.$set ...
setTimeout(() => { this._suppressUpdate = false; }, 350);
```

### Wire Watch — Avoid Re-entrant Loops
```js
init() {
    this.$wire.$watch('{{ $statePath }}', (val) => {
        if (this._suppressUpdate) return;
        this._lat = val?.latitude  ?? null;
        this._lng = val?.longitude ?? null;
        this.address    = val?.address    ?? '';
        this.structured = val?.address_details ?? null;
    });
},
```

## 10. ARCHITECTURE (HOW)

### PHP Trait: `HasCoordinatePicker`
Handles fluent methods: `latitude()`, `longitude()`, `zoom()`, `center()`, `height()`, `reverseGeocoding()`.
Server methods: `reverseGeocode(float $lat, float $lng): ?array`, `searchAddress(string $query): array`.

### Blade View
Uses `x-dynamic-component` with `:component="$getFieldWrapperView()"`.
Contains: Alpine x-data, search input, `<coordinate-picker-lit>`, address readout, aria-live region.

### Lit Component: `coordinate-picker-lit.js`
- Pure UI + Leaflet logic. Stateless w.r.t. server.
- Light DOM for Leaflet compatibility.
- Dispatches: `coords-changed`, `fullscreen-changed`.
- Accepts: `latitude`, `longitude`, `zoom`, `height`, `isExpanded`, `labels` (JSON).
- Uses `ResizeObserver` for `invalidateSize()`.
- Cleans up in `disconnectedCallback()`.

### Alpine: Minimal Bridge
- `init()`: `$wire.$watch`
- `handleCoordsChanged()`: `$wire.$set`
- `reverseGeocode()`: server method call
- `searchAddress()`: server search

## 11. BEST PRACTICES ✅

- **Use Light DOM** for Leaflet. Shadow DOM breaks marker icons, CSS panes and layer controls.
- **One state object** per field: always `{ latitude, longitude, address, street, ... }`.
- **Debounce search** at 500ms.
- **Respect Nominatim Usage Policy** — User-Agent header, 1 req/sec max, no bulk geocoding.
- **Cache reverse geocode** results (Redis, 1h TTL).
- **Use `#[Renderless]`** on `reverseGeocode` and `searchAddress`.
- **Use `ResizeObserver`** for `invalidateSize()`.
- **Provide fallback center** (Rome: 41.9028, 12.4964).
- **Provide fallback UI** when geolocation denied.
- **All buttons** must have `type="button"`, `aria-label`, `title`.
- **Accessibility**: always `<div aria-live="polite" class="sr-only">`.
- **Layer names** from i18n.
- **SearchAddress** min query length ≥ 3 chars.
- **`countrycodes` param** in Nominatim search.
- **`@keydown.escape`** to close dropdown.
- **Clean up** in `disconnectedCallback()`.

## 12. BAD CASES ❌ — Never Do This

| Bad Practice | Why Wrong | Correct Alternative |
|---|---|---|
| `LatitudeLongitudeInput extends CoordinatePicker` | Tight coupling | Sibling pattern |
| `id="map"` or `document.getElementById()` | ID conflicts | Local class `.coordinate-picker-map` |
| `wire:entangle` on Lit web component | Event loops | `$wire.$set` + `$wire.$watch` with `_suppressUpdate` |
| Separate `lat`/`lng` Alpine vars | Breaks SoT | Single state object |
| Calling Nominatim directly from JS | Exposes IP, no cache | Route through Livewire |
| `navigator.geolocation` on mount | Invasive prompt | Explicit button only |
| Livewire on every `mousemove`/`drag` | Performance thrashing | `dragend`, `click`, `geolocation success` only |
| Hardcoding Italian strings in JS | Breaks i18n | Pass via `labels` JSON attribute |
| `shouldUpdate()` for state sync | Misuse of Lit hook | `updated()` with `_isProgrammaticUpdate` guard |
| No `invalidateSize()` after resize | Blank tiles | ResizeObserver + setTimeout |

## 13. FALSE FRIENDS ⚠️ — Common Misconceptions

| False Belief | Reality |
|---|---|
| Shadow DOM better for encapsulation | Leaflet breaks in Shadow DOM. Use **Light DOM**. |
| Automatic geolocation on mount | Invasive. Make it explicit. |
| `shouldUpdate()` for state sync | Only for re-render optimization. |
| `marker.setLatLng()` immediate after init | Wait for `invalidateSize()` + debounce. |
| `entangle` simpler than `$wire.$set` | Creates feedback loops. Use explicit sync. |
| Store lat/lng in Alpine for speed | Breaks SoT. Livewire is the truth. |
| Geocoding client-only | Must go server-side for rate-limiting. |
| One Leaflet zoom control enough | Custom controls + `zoomControl: false`. |
| Layer control optional | 4 layers REQUIRED. |
| GPS coordinates always floats | Nominatim returns strings. `parseFloat()`. |
