# Metodo per Massimizzare la Confidenza dell'Agente

## Principi Fondamentali
- **Second Brain first**: qmd search + TRIGGER_MAP prima di qualsiasi azione.
- **GitHub Issue come Audit Trail**: git remote -v + issue obbligatoria (mai saltare).
- **Contesto Pulito**: solo token-optimizer_smart_* + compress + acm_prune/acm_scan. Contesto sporco = allucinazioni.
- **Quality Gates Post-Edit**: FLVP (file lock + PHPStan + PHPMD + PHPInsights) dopo ogni modifica.
- **Dubbio Esplicito**: documentare sempre dubbi, perplessità, zen, politica, religione, filosofia quando rilevanti.
- **Propagazione Distribuita**: ogni conoscenza importante deve finire nei docs di moduli e temi (non solo root).
- **Verifica Multi-Fonte**: wiki + codice + git log + issues + test + esecuzione reale.

## Passi Operativi per Alta Confidenza
1. Carica regole rilevanti via qmd (limite 5).
2. Apri/usa issue GitHub dedicata.
3. Usa solo tool a basso impatto token.
4. Dopo edit → quality gates.
5. Documenta dubbi + riflessioni zen.
6. Propaga in moduli/temi.
7. Comprimi sezioni chiuse.

## Perché Funziona
Riduce errori di contesto, allucinazioni, dimenticanze di regole, e garantisce che la conoscenza sia viva e distribuita.

**Applica questo metodo in ogni task di analisi (es. redundancy) per confidenza massima.**
