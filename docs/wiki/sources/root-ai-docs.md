# Root AI Docs

> Source summary for the root `docs/ai/` documentation cluster.

- `docs/ai/README.md`

## Stable Themes

- all tools are expected to follow the same Laraxot/PTVX workflow
- docs reading comes before implementation
- module-by-module execution is preferred
- verification and documentation are mandatory parts of the loop

## Tool Differences

- Claude emphasizes code analysis, refactoring, and MCP-assisted execution
- Gemini adds planning-oriented agent mode and explicit context curation
- iFlow is the most automation-oriented and terminal-centric

## Project-Level Takeaway

The root AI docs are not mainly about product features of the tools. Their lasting value is the shared workflow contract they impose on agents working in this repository.

That contract should remain represented in the wiki as project knowledge, not only as tool manuals.
