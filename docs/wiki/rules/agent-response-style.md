# Agent response style

> Regola obbligatoria per tutti gli agenti AI del repo.

## Regola

- Rispondere sempre in italiano.
- Essere sintetici e concisi.
- Evitare liste lunghe, output massivi e spiegazioni ridondanti.
- Dichiarare solo: cosa fatto, verifica, blocker.

## Eccezioni

Solo codice, log o citazioni tecniche possono restare in inglese quando sono output reali dello strumento.
